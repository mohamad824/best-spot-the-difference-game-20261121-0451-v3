Gem Rush — Spot the Difference. A complete, original spot-the-difference game in saturated jewel colours: three hand-drawn scenes (a glowing Crystal Temple, a cosy Clockmaker's Workshop, a moonlit Firefly Garden) with 5, 7 and 9 fair differences; a named found-list, a 2× hover magnifier, hints, hearts, streaks, stars, par times and WebAudio sounds. Keyboard + mouse play, fully offline — every file lives under game/.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome.
